# Investment Tracking and Analysis Application

## Overview
This is a comprehensive Python-based investment tracking and analysis application that helps users manage their investment portfolio, analyze stock performance, and make informed investment decisions.

## Features
- Portfolio Management
- Stock Performance Analysis
- Risk Assessment
- Investment Recommendations
- Visualization of Investment Data

## Installation
1. Clone the repository
2. Create a virtual environment
3. Install dependencies:
```bash
pip install -r requirements.txt
```

## Running the Application
```bash
streamlit run main.py
```

## Dependencies
- Python 3.9+
- yfinance for stock data
- pandas for data manipulation
- matplotlib and plotly for visualization
- scikit-learn for machine learning components
